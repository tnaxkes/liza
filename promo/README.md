# Промо-ролик

`promo_9x16.mp4` — 19 сек, 1080×1920, 30 fps, без звука (накладывай музыку в редакторе).

## Сценарий

| время | что |
|---|---|
| 0.0–2.4 | «цветы» / «шарики» / «конверт» — зачёркиваются по очереди |
| 2.4–3.6 | «а можно **иначе.**» |
| 3.6–10.3 | телефон: реальные экраны мини-аппа, быстрые склейки с подписями |
| 10.3–11.6 | «а ты — видишь каждый шаг» + карточки уведомлений |
| 11.6–14.6 | чипы: что входит |
| 14.6–19.0 | «не вещь. / а вечер.» → финальная плашка + ник |

## Что поправить под себя

Всё в `promo.html`:

- **ник в финале** — найди `@nickname` (это плашка `#f5`)
- **тексты чипов** — блок `<div class="layer" id="a3">`
- **подписи к экранам** — массив `SHOTS` в конце файла (`cap` и `kick`)
- **финальные строки** — `#f1`, `#f2`, `#f3`, `#f4`
- **длительность** — `const DUR = 19.0` (тайминги сцен считаются в секундах внутри `seek()`)

## Перерендерить

```bash
cd promo
npm i --cache /tmp/npmcache
node render.mjs        # кадры -> frames/
ffmpeg -y -framerate 30 -i frames/%05d.jpg -c:v libx264 -preset veryslow -crf 22 \
  -pix_fmt yuv420p -movflags +faststart -r 30 promo_9x16.mp4
```

Превью в браузере: открой `promo.html` и выполни в консоли `play()`.

## Пересъёмка экранов мини-аппа

`shots/*.png` сняты скриптом `capture.mjs` с живого мини-аппа (`lib/page.mjs` из корня проекта).
Он сам размывает фотографии и подменяет имя на нейтральное — при пересъёмке это сохранится.

```bash
node capture.mjs
```

Хочешь другое имя вместо «Аня» — поправь в `capture.mjs` строку `[..."Аня"]`.

## Важно

Фотографии в ролике намеренно размыты до неузнаваемости. Если будешь ставить
реальные кадры — спрашивай разрешение у людей на них.
