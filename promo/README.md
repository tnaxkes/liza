# Промо-ролик

`promo_9x16.mp4` — 20 сек, 1080×1920, 30 fps, без звука (музыку накладывай в редакторе).

## Сценарий

| время | что | визуал |
|---|---|---|
| 0.1–5.3 | **боли**: «цветы» / «конфеты» / «конверт» | линейная иконка рисуется → умирает (цветок вянет, коробка пустеет, деньги улетают) + полоска «сколько живёт» вытекает до нуля + вердикт |
| 5.3–6.6 | «а можно — иначе.» | искра загорается, расходятся два кольца |
| 6.6–14.1 | **продукт**: живые записи мини-аппа | палец реально тыкает по интерфейсу — держит фитиль, задувает свечи по одной, отмечает пожелания, листает фото |
| 14.1–15.2 | «а ты — видишь каждый её шаг» | телефон уезжает влево, справа влетают карточки уведомлений |
| 15.2–17.8 | **превосходство** | таблица «обычный / этот», крестики и галочки прорисовываются |
| 17.8–20.0 | «не вещь. а вечер.» | финальная плашка + ник, расходящееся кольцо |

Переходы — кросс-фейды 0.36с, вспышек всего три и мягкие.

## Что поправить под себя

Всё в `promo.html`:

- **ник в финале** — найди `@nickname` (блок `#f5`)
- **боли** — блоки `.pain` (`#p0`, `#p1`, `#p2`): слово в `.pw`, вердикт в `.vd`, иконка — inline SVG
- **строки сравнения** — блок `#a3`, каждая `.row`
- **подписи к экранам** — массив `CLIPS` в скрипте (`kick` и `cap`)
- **финальные строки** — `#f1`…`#f5`
- **все тайминги** — константы `PAIN`, `BR`, `CLIPS`, `NT`, `CM`, `FN` в начале скрипта, в секундах

## Перерендерить

```bash
cd promo
npm i --cache /tmp/npmcache
node render.mjs
ffmpeg -y -framerate 30 -i frames/%05d.jpg -c:v libx264 -preset veryslow -crf 21 \
  -pix_fmt yuv420p -movflags +faststart -r 30 promo_9x16.mp4
```

Превью в браузере: открой `promo.html` через локальный сервер (не `file://`, иначе не подтянутся кадры) и выполни в консоли `play()`.

## Перезаписать анимации мини-аппа

`clips/*` — это настоящие записи живого мини-аппа (`lib/page.mjs` из корня проекта),
снятые через Chrome DevTools Protocol на 60 fps и приведённые к 30. Вместе с ними
пишется `clips/manifest.json` с координатами тапов — по ним в ролике двигается палец.

```bash
node capture.mjs
```

Имя в демо — «Аня» (подменяется на лету, строка `const NAME` в `capture.mjs`).
Фотографии показываются как есть; если нужно скрыть лица — добавь в `capture.mjs`
`page.addStyleTag({content:'.pl img{filter:blur(17px)}'})` после загрузки страницы.
